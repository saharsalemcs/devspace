## How to Use This Document

- Phases are **sequential** — Phase N+1 assumes Phase N is (mostly) complete.
- Within a phase, tasks are ordered to minimize rework.
- Each task should take **≤ 2 hours**. If it takes longer, split it further.
- Tag a Git commit at the end of each phase (e.g., `phase-2-complete`) as a rollback checkpoint.
- Don't skip **Phase 0** or **Phase 1** — the whole build stands on them.

**Total:** 11 phases · ~200 small tasks · MVP-shippable.

- [ ] `cart_items`: users full access to own rows only
